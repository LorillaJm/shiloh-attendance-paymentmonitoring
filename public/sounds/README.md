# Notification Sounds

Place your notification sound file here as `notification.mp3`.

## Recommended:
- Short duration (1-3 seconds)
- Pleasant tone (not jarring)
- File size under 100KB

## Free Sound Resources:
- https://notificationsounds.com/
- https://freesound.org/
- https://mixkit.co/free-sound-effects/notification/

## Usage:
The sound will play when push notifications are received while the app is open.
